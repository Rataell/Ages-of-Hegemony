Auditoria dos recortes

Chassi oculto: o que a civilização define

A civilização define Trait, Limitation, Assinatura, Heranças, arquitetura, estandarte, emblema e identidade. A Figura define Passiva, Poder 1× por Era, retrato e um pequeno direcionamento estratégico. As regras vêm dos chassis atuais, sem alteração; só o nome de exibição muda.

B · Três Figuras de cada civilização

Retratos são composições-placeholder numa só linguagem. Nem toda Figura governou: há generais, heróis, exploradores, profetas, sábios e estrategistas.

C · Seleção de Figura (Helênicos)

Civilização → mostra três Figuras; uma vem marcada como recomendada para iniciantes; o jogador escolhe uma; em multiplayer as escolhas são reveladas ao mesmo tempo.
