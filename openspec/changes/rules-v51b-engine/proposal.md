# Rules V5.1b engine migration

Baseline: `docs/product/rules-v5-proposal.md` (V5.1b FINAL, commit 2341733). No V5.2. A rule changes only when implementation
or playtest shows a real contradiction, and the change is first written in `design.md` § Interpretations.

Scope: domain → engine → server/projection → UI V2.2 → playtest, end to end.
V5.1a (economy, city, population, Orders, Web 40+10, Heritage, administration, Hegemony) is already in the engine and stays.
What V5.1b adds or replaces:

- Ressonância (5 sockets) + Repercussão replace Pressão do Mundo.
- Combat: one tactical shock, Δ semantics, family Power + signature, Graus I–III.
- World threats: Acampamentos, Bandos, Piratas, Encontros/Descobertas, event commands.
- Virada de Era in 9 steps; Governo only at the Era turn.
- Tabuleiro da Civilização + Reserva de Marcos + Faixa of 5 sockets in the product UI.
